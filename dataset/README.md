# Training data

Datasets are intentionally excluded from Git. Their original download URLs and redistribution licenses were not included in the archive, so this repository does not redistribute them.

The notebooks use `spam_ham_dataset.csv` with the fields `label`, `text`, and `label_num` (0 = ham, 1 = spam). An extra index column may be present. Obtain the dataset from its original publisher, verify its terms, and record its source before sharing it.

The archive also contained `emails.csv` (about 1.33 GiB; columns `file` and `message`). Keep it outside Git. No provenance is asserted here.

Notebook paths need to be adjusted for your local environment; see the root README.
